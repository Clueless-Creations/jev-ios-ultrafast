# Measurement protocol

## Visual

Keep original-resolution evidence. Record verified pixel scale before converting to logical units.

Measure relationships before obsessing over individual numbers:

- baseline alignment
- vertical rhythm
- content width
- repeated inset values
- component anatomy
- hierarchy
- density
- cropping rules
- safe-area behavior

## Motion

Do not estimate motion from a single before/after screenshot.

For each animated property record:

- start/end state
- path
- duration range
- onset/delay
- overlap
- stagger
- easing evidence
- overshoot/settle
- clipping/masks
- interruption behavior
- reversal behavior

Only claim exact curves/constants when measured or instrumented.

## Haptics

Video alone cannot verify haptics.

Use one of:

- human physical observation
- calibrated external sensor
- authorized source instrumentation

Otherwise mark the behavior unknown or blocked.

## Audio

A recording pipeline without audio does not prove the app is silent.
