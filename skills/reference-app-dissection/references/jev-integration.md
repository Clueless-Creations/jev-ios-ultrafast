# Jev integration

Use Jev for bounded semantic orientation and safe navigation when the reference is available on an iOS Simulator.

Good uses:

- identify accessible controls
- sample navigation structure
- reach representative states
- create a compact semantic map

Do not use Jev output as evidence for:

- visual quality
- exact spacing
- typography
- colors
- animation curves
- gesture physics
- haptics
- audio
- exhaustive coverage

The current repository runtime does not natively provide physical-iPhone or Android Jev execution. Keep those transports separate until explicitly implemented.

Do not replay runtime target IDs across observations/devices.
