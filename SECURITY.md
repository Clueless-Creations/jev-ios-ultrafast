# Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Clueless-Creations/jev-ios-ultrafast/security/advisories/new) for a suspected security issue. Include the affected revision, a minimal fixture reproduction, and the expected and observed behavior. Do not include active credentials or private app data.

Use public issues for ordinary bugs. The maintained version is the latest `main`; security fixes are published there.
